# Bouncing Ball (Unity 2D Game)

## Overview
Bouncing Ball is a 2D game developed in Unity, featuring simple UI and engaging gameplay mechanics. The project includes 40 unique levels, each designed to challenge the player in different ways.

## Features
- 40 handcrafted levels
- Simple and intuitive UI
- Custom gameplay mechanics
- User feedback-driven improvements

## Getting Started
### Prerequisites
- Unity (recommended version: 2021.3 LTS or later)
- macOS or Windows

### How to Run
1. Clone or download this repository.
2. Open the project in Unity Hub.
3. Open the `Scenes` folder and select a scene to start playing or editing.
4. Press the Play button in the Unity Editor.
5. instructions is provided when you click `how to play` in first scene

## Folder Structure
- `Assets/` – Game assets, scenes, scripts, and localization files
- `Library/`, `obj/`, `Logs/`, `Packages/`, `ProjectSettings/`, `UserSettings/` – Unity project and build files
